Project Overview

A production-grade, passive network monitoring and packet analysis platform built for the CodeAlpha cybersecurity internship. It captures traffic from an authorized network interface, parses protocol metadata with Scapy, stores sanitized records in Django's ORM, and presents a professional SOC-style dashboard with analytics, DNS analysis, filtering, reporting and passive anomaly indicators.

Core Features

Live Packet Capture

Background capture worker with interface selection, packet limits, timeouts and protocol filters — without ever blocking the web server.

Protocol Analysis

IPv4, IPv6, TCP, UDP, ICMP, ICMPv6, ARP and DNS metadata extraction with defensive layer handling for malformed packets.

Security Analytics

Traffic timelines, protocol distribution, top IPs/ports, packet-size histograms and clearly-labeled passive anomaly indicators.

DNS Analysis

Query frequency, first/last seen, query types and response codes with search and filtering.

Reporting

One-click CSV, JSON and standalone HTML reports per capture session, generated in memory with validated session IDs.

Privacy by Design

Payload previews disabled by default, strictly size-limited, configurable retention and explicit session deletion.

Supported Protocols

IPv4 IPv6 TCP UDP ICMP ICMPv6 ARP DNS

Architecture

Packet capture runs in a separate worker from the Django web application, sharing only the database.

How It Works

1. An administrator selects an authorized interface and starts a capture.
2. The capture worker parses each packet defensively and stores sanitized metadata.
3. The dashboard aggregates statistics, timelines and DNS activity.
4. Analysts search packets, inspect protocol details and generate reports.

Ethical Use

This is a passive network monitoring and analysis platform. It does not implement injection, modification, interception of unauthorized traffic, credential harvesting or any offensive capability. Only monitor networks and devices that you own or have explicit authorization to monitor. Unauthorized network interception is illegal in most jurisdictions.
