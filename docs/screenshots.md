# Screenshots

This directory stores screenshots for the CodeAlpha submission.

> **Note on honesty:** the application never displays fabricated traffic.
> Screenshots in this folder may show a live capture taken on an authorized
> network, or may be placeholders (`screenshots/.gitkeep`). They are kept
> separate from the application itself so the application never mixes sample
> data with real captured data.

## Suggested screenshot set

| File | Content |
|------|---------|
| `screenshot-01-landing.png` | Public landing page |
| `screenshot-02-dashboard.png` | Dashboard with metric cards and charts |
| `screenshot-03-capture.png` | Live Capture page while capturing |
| `screenshot-04-session.png` | Session detail with protocol/timeline tabs |
| `screenshot-05-explorer.png` | Packet explorer with filters |
| `screenshot-06-packet-detail.png` | Packet detail with protocol stack |
| `screenshot-07-analytics.png` | Traffic analytics with anomaly indicators |
| `screenshot-08-dns.png` | DNS analysis page |
| `screenshot-09-report.png` | HTML report preview |

To capture them, run the app, sign in, and use your operating system's
screenshot tool.

## Screenshot ethics

- Blur or crop any personal or sensitive information (real IPs, hostnames,
  DNS names) before publishing.
- Only include captures made on networks you own or are authorized to monitor.
